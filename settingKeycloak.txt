Eseguire il seguente comando per aprire un tunnel alla porta 8082 e potersi connettere a keycloak

minikube kubectl -- port-forward -n progetto svc/mio-keycloak 8082:80

Aprire la pagina web http://127.0.0.1:8082 e entrare nella dashboard digitando
utente: admin
pswd: Admin1234!


CREAZIONE REALM
Click Manage realms nella colonna a sinistra.
Click Create realm.
Enter progetto nel Realm name field.
Set enabled on
Click Create.
Controllare in alto a destra di essere nel realm appena creato, alternativamente click menage relams e click progetto

CREAZIONE CLIENTS

Click clients
Click create clients
Settare:
	Client type: OpenID Connect
	Client ID: oauth2-proxy
	Always display in UI: active
Click next
Settare: 
	Client authentication: on
	Standard flow: on
Click next
Set
	Valid redirect URIs: http://localhost:8081/oauth2/callback
	Web Origins: http://localhost:8081
Click save

CREAZIONE DI UN UTENTE
click users
click create user
Settare:
	email verified: on
	username: pippo
	email: pippo@prova.it
	first name: pippo
	last name: pluto
Click create
Click sulla credentials section
click set password
Settare:
	Password: Admin1234!
	Password confirmation: Admin1234!
	Temporary: off
click save

FINE PROCESSO
click sul proprio nome utente in lato a destra
click su log out
Chiudere il tunnel con ctrl+c
